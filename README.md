# Junk to Gold

This module will automatically sell gray items when the player loots them

## Configuration

`JunkToGold.EnableSaleChat` (default: `1`)

- `1`: Send chat messages when gray items are auto-sold.
- `0`: Disable sale chat messages for quieter operation and slightly less overhead.
